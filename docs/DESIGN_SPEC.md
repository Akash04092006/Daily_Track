# Design spec (Phase 3, part 1)
Charcoal glass, dark first. Tokens in src/app/glass.css. Font: Figtree via next/font (variable --font-figtree).
Accent: brass (#E3B866 dark / #A9762B light), used only for the active nav pill, checked habits and the progress ring.
Nav: floating glass pill, sticky. Signature element: the daily progress ring.
Rules: use .glass / <GlassCard> for surfaces, text-fg / text-muted / bg-accent for color, no hardcoded hex.
Part 2 (not built yet): Habits, Calendar heatmap, Analytics, Goals, Settings, Login/Signup, empty and loading states.
